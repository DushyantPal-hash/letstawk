GET STARTED

Custom Connector in Action

Here's how simple it is to build a custom connector with the Letstawk framework.

// Custom Connector Configuration
const connector = {
  name: "Custom CRM Sync",
  version: "1.0.0",
  authentication: {
    type: "oauth2",
    clientId: "{{env.CLIENT_ID}}",
    clientSecret: "{{env.CLIENT_SECRET}}"
  },
  mapping: {
    lead_to_crm: {
      source: "letstawk.lead",
      target: "crm.contact",
      fields: {
        first_name: "lead.firstName",
        last_name: "lead.lastName",
        email: "lead.email",
        score: "lead.qualification.score"
      }
    }
  },
  webhooks: {
    on_qualify: "https://api.crm.com/leads",
    on_complete: "https://api.crm.com/call_logs"
  }
};

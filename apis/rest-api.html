REST API in Action

Simple, clean, and powerful. Here's how to initiate a voice call with Letstawk's REST API.

// Initiate an outbound voice call with Letstawk
POST https://api.letstawk.com/v1/calls
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY
